# Activating the License

The V-90 plug-ins use iLok licensing. A license can be activated on your computer or on an iLok USB key, which makes it easy to move the license between computers. You can [learn more at ilok.com](https://ilok.com).

## Activate a License

1. Launch your DAW and insert a V-90 plug-in.
2. When the licensing window appears, select **Activate**.
3. Enter your iLok ID and password.
4. Select the V-90 license and select **Next**.
5. Choose the location for the license: your computer or an iLok USB key.

The plug-in is now licensed and ready to use.

## Try Before You Buy

If you do not have a license, select **Try** in the licensing window of any V-90 plug-in. This puts a V-90 Complete trial in your iLok account: trial licenses for all four V-90 licenses, so you can try all five plug-ins.

## Which License Covers Which Plug-In

| License | Plug-ins |
|---|---|
| V-90 Symphonic | V-90 Symphonic |
| V-90 Reverbs & Reflections | V-90 Reverbs and V-90 Reflections |
| V-90 Modulations | V-90 Modulations |
| V-90 Pitch Change | V-90 Pitch Change |

**V-90 Complete** is all four licenses sold together. When you buy V-90 Complete, your iLok account receives the four licenses above. Activate each one as described above.
