# Installation

The **V-90 Complete** installer installs all five V-90 plug-ins: Symphonic, Reverbs, Reflections, Modulations and Pitch Change.

| Platform | Formats installed |
|---|---|
| macOS | AAX, AU, VST 3 |
| Windows | AAX, VST 3, VST |

The AAX plug-ins include AAX Native and, for Symphonic, Reverbs, Modulations and Pitch Change, AAX DSP for Pro Tools HDX systems.

## Install

1. **Download the installer.** Use a web browser to open the [Neyrinck V-90 page](https://neyrinck.com/v90) and download the installer for your computer.
2. **Quit your DAW** and close all other running apps.
3. **Run the installer** and follow the steps. It installs the plug-ins in the standard plug-in folders, and the shared V-90 graphics they need.
4. **Launch your DAW.** The plug-ins appear under the manufacturer name Neyrinck Audio.

!!! note
    The V-90 Complete installer installs over earlier V-90 Symphonic, Reverbs and Pitch Change releases.

## Plug-In Locations

=== "macOS"

    | Format | Folder |
    |---|---|
    | AAX | /Library/Application Support/Avid/Audio/Plug-Ins |
    | AU | /Library/Audio/Plug-Ins/Components |
    | VST 3 | /Library/Audio/Plug-Ins/VST3 |

=== "Windows"

    | Format | Folder |
    |---|---|
    | AAX | C:\Program Files\Common Files\Avid\Audio\Plug-Ins |
    | VST 3 | C:\Program Files\Common Files\VST3 |
    | VST | The VST folder you choose during installation |

    The shared graphics are installed in `C:\ProgramData\Neyrinck\V-90\Resources`.

## Uninstall

Delete the V-90 plug-ins from the folders above.
