# System Requirements

## Computer

| | |
|---|---|
| macOS | macOS 10.13 or later, Apple silicon and Intel |
| Windows | 64-bit Windows |
| License | An iLok account; the license on your computer or an iLok USB key |

### AAX DSP

On Pro Tools HDX systems, these plug-ins can run on the DSP:

| Plug-in | AAX DSP |
|---|---|
| V-90 Symphonic | ✓ |
| V-90 Reverbs | ✓ |
| V-90 Modulations | ✓ |
| V-90 Pitch Change | ✓ |
| V-90 Reflections | AAX Native only |

Reverbs, Modulations and Pitch Change each need one DSP chip at 96 kHz.

## Track Formats

The plug-ins are **mono-to-stereo** and **stereo-to-stereo**. See [Signal Flow and Track Formats](../using/signal-flow.md).

## Sample Rates

44.1, 48 and 96 kHz.
