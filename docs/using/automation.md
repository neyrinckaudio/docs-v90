# Automation

Every V-90 parameter can be automated and controlled from a control surface.

## Parameter Order

The parameters appear in your DAW in this order:

1. **Memory** (not in V-90 Symphonic)
2. **Input**
3. **Balance**
4. The program parameters, named in title case (for example, "Rev Time", "Room Size", "Mod Depth")
5. **Bypass**

Each plug-in page lists the host name of every parameter.

## Lists and Switches

These parameters are discrete: your DAW shows them as lists or on/off switches and never ramps between values.

* Memory
* Reflections' Type
* Modulations' Direction (Auto Pan)
* Pitch Change's Base Key
* MIDI Trigger (Reverb & Gate, Delay Vibrato)
* Bypass

## Automation and Memories

The parameters you automate are the playing memory's. When automation changes **Memory**, the new memory's own settings come in. An automation point on another parameter at the same moment as the memory change applies to the new memory.

!!! tip
    To switch between programs during a song, automate **Memory**, then write each memory's settings while it plays.

## Values Are the Unit's Steps

Each parameter moves in the original unit's steps. Your DAW shows the value as the unit does, for example `2.6s` or `8.0 kHz`.
