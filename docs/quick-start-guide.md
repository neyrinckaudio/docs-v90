# Quick Start Guide

1. **Install.** Run the V-90 Complete installer for your computer. See [Installation](getting-started/installation.md).
2. **Insert a plug-in.** In your DAW, insert a V-90 plug-in on a mono or stereo track, or on a stereo aux/bus used as an effect return. The plug-ins are listed under Neyrinck Audio and in the Reverb, Modulation, Delay and Pitch Shift categories.
3. **License.** The first time the plug-in opens, the iLok licensing window appears. Select **Activate** if you have a license, or **Try** to start a trial. See [Activating the License](getting-started/licensing.md).
4. **Set the input level.** Play audio and turn the **INPUT** knob so the meter peaks in the green, with only occasional orange. The knob's default (8) is unity gain.
5. **Choose a program.** Press the **MEMORY ▲/▼** keys (right of the BALANCE key). The memory number blinks and the LCD shows the program's name. Press **RECALL** to load it.
6. **Edit.** Press **PARAMETER** to step through the program's parameters, and the **▲/▼** keys next to it to change the value shown on the LCD. You can also drag on the LCD, or click it to type a value.
7. **Set the balance.** Press **BALANCE** and set the dry/effect mix. On an effect return, set BALANCE to 100 %.

!!! tip
    Option-click (Alt-click on Windows) the LCD to return the parameter shown to its factory value.

## Using V-90 as an Effect Return

1. Create a stereo aux or bus track and insert the V-90 plug-in on it.
2. Send to it from the tracks you want to process.
3. Set **BALANCE** to **100 %** so the return carries only the effect.

## Using V-90 as an Insert

Insert the plug-in directly on the track and use **BALANCE** to set how much effect you hear. A mono track becomes stereo after the plug-in.
